## `ish study get`

Get the full study payload - iterations (with run details), assignments, interview questions, sentiment + status counts. Accepts multiple IDs for batched lookup. NOTE: this is the full payload, not a roll-up - for a compact cross-study comparison view use `study results &lt;id&gt; --summary`.

## `ish study benchmark`

Run a study's benchmark against one or more references. Clones the study onto each reference, appends a round, and dispatches simulations: RUNS and draws credits.

Usage: `ish study benchmark [id] [options]`

### Arguments
<ParamField path="id">Study ID (defaults to active study) (optional)</ParamField>

### Options
<ParamField path="--reference <id>" type="string">Reference id to benchmark against (repeatable; comma-separated accepted). At least one required. Default: []. Required.</ParamField>
<ParamField path="--source-iteration <id>" type="string">Source-study iteration whose completed AI participant roster each round replicates. Required.</ParamField>
<ParamField path="--screen <format>" type="string">Screen format for every round: desktop | mobile_portrait (default desktop)</ParamField>
